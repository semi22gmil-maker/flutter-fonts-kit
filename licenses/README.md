# المستندات

هذا المجلد لحفظ تراخيص الخطوط الأصلية المطلوبة شرعاً عند إعادة توزيعها.

كل الخطوط داخل `assets/fonts/` مصدرها مستودع [Google Fonts](https://github.com/google/fonts)
الرسمي، وكلها بترخيص **SIL Open Font License 1.1 (OFL-1.1)** بلا استثناء.

## ماذا تسمح رخصة OFL-1.1؟

- ✅ الاستخدام الشخصي والتجاري داخل التطبيقات والمواقع.
- ✅ التعديل وإعادة التوزيع ضمن منتج أكبر.
- ❌ بيع ملفات الخط منفردة.
- ❌ إعادة تسمية الخط واستخدام اسمه المحجوز لنسخة معدّلة.
- ⚠️ يجب تضمين نص الرخصة مع كل نسخة معاد توزيعها (نحن نفعل ذلك هنا).
